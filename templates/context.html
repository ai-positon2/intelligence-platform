Chapter 01

What is Intelligence?

The short answer, before the details.

Intelligence is Position²'s single front door to a fleet of AI agents that do real go-to-market and SEO work — from spotting buying signals to writing content briefs — all behind one Google login.
✓ 18 agents under one roof — GTM and SEO, side by side
✓ Most run with zero setup — pick one and go
✓ Point-and-click — no code, no technical know-how
✦

    What it is

  • A friendly home for powerful agents
  • A shared workspace for whole teams
  • Ready-to-use tools with clean outputs

    What it isn't

  • Not a raw, technical back-end
  • Not one-off scripts scattered around
  • Not something only engineers can touch
Chapter 02

Why we built it.

The vision, in one before-and-after.

Before

Great agents, no front door

Arena is packed with powerful AI agents — but they live in a technical back-end built for engineers. There was no friendly, interactive front-end, so the people who needed these agents most couldn't actually use them.

→
After

A home anyone can use

So we built Intelligence: a beautiful, interactive homepage for the whole fleet. The majority of agents are still powered by Arena under the hood — this platform is the front-end that lets anyone pick an agent and put it to work.

Arena is the engine. Intelligence is the cockpit — where anyone can actually fly it.
